# 예술의전당 세계음악분수 (웹 체험)

예술의전당 음악광장을 걸어 다니며, 음악에 맞춰 산맥·갓·난초·학날개·안개·발레분수가 춤추는 장면을 보는 웹 페이지입니다.

- 4곡이 정해진 시간표대로 흘러서, 언제 들어와도 모두 같은 장면을 봅니다.
- 곡마다 배경이 한낮 → 노을 → 야경으로 바뀝니다.
- 휴대폰에서 "홈 화면에 추가"하면 앱처럼 전체 화면으로 열립니다.

## 사용법
1. 페이지를 열고 "눌러서 입장하기"를 누르면 소리와 함께 공연이 시작됩니다.
2. 화면을 끌어서 걷고, 바닥을 누르면 그곳까지 걸어갑니다.
3. 물 위를 누르면 소원 물줄기가 솟습니다.

## 알아 두기
- 음악은 저작권 보호기간이 끝난 클래식(파헬벨·베토벤·요한 슈트라우스 2세)과 창작곡을 브라우저에서 직접 합성합니다.
- 배경 사진은 AI(Codex)로 생성한 이미지로, 실제 건물과 세부가 다를 수 있습니다.
- 같은 주소로 들어온 사람끼리 광장에서 만나요. 위치·색·별명만 공개 MQTT 중계 서버(broker.emqx.io)를 거쳐 전달되고, 이름·계정 정보는 보내지 않습니다.
- 공개 중계 서버는 무료 공용 서버라 가끔 느리거나 끊길 수 있어요. 많은 인원이 쓰는 행사용으로는 전용 서버(Cloudflare 등)로 바꾸는 것을 권장합니다.
